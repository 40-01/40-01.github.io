2个性化配置

打开 hugo.yaml，修改以下带 TODO 标记的内容：

基本设置

# 站点标题和域名
baseURL: "https://www.yourdomain.com/"  # ← 替换为你的域名
title: "你的博客名称"                      # ← 替换为你的博客名
params:
  author: "你的名字"                      # ← 替换为你的名字
  description: "你的博客描述"
  homeInfoParams:
    Title: "你好 👋"
    Content: "首页欢迎语"                # ← 自定义首页内容

社交链接

socialIcons:
  - name: "github"
    url: "https://github.com/你的用户名"  # ← 替换
  - name: "email"
    url: "mailto:你的邮箱@example.com"     # ← 替换

CNAME 文件

编辑 static/CNAME，写入你的域名：

www.yourdomain.com
提示：如果你的域名是裸域 (如 yourdomain.com)，CNAME 文件写裸域；如果用 www 子域，就写 www.yourdomain.com。

3推送到 GitHub 仓库

你已有 GitHub 仓库，只需把博客项目推上去：

方式一：推送到现有仓库（覆盖）

注意：如果你的仓库已有其他内容，请先备份！以下命令会覆盖远程仓库内容。 
cd blog

# 添加远程仓库 (替换为你的仓库地址)
git remote add origin https://github.com/你的用户名/你的仓库.git

# 提交所有文件
git add .
git commit -m "初始化 Hugo 博客"

# 强制推送 (如果仓库已有内容)
git push -u origin main --force

方式二：推送到空仓库

cd blog
git remote add origin https://github.com/你的用户名/你的仓库.git
git add .
git commit -m "初始化 Hugo 博客"
git push -u origin main
主题是子模块：推送后，在 GitHub 仓库页面会看到 themes/PaperMod.git 指向原仓库。这是正常的。GitHub Actions 部署时会自动拉取主题。

4配置 GitHub Pages

  1. 进入你的 GitHub 仓库 → Settings
  2. 左侧菜单找到 Pages
  3. Source 选择 GitHub Actions
  4. 推送代码后，Actions 会自动构建部署
  5. 在 Actions 标签页可以看到构建日志
重要：不要选择 "Deploy from a branch"，必须选 GitHub Actions，因为我们用的是 Actions 自动部署。

5配置 Cloudflare DNS

你已将域名托管到 Cloudflare，需要添加 DNS 记录指向 GitHub Pages。

方案 A：使用 www 子域（推荐）

类型名称内容代理
CNAMEwww你的用户名.github.io仅 DNS (灰色)
CNAME@你的用户名.github.io仅 DNS (灰色)

方案 B：使用裸域

类型名称内容代理
A@185.199.108.153仅 DNS (灰色)
A@185.199.109.153仅 DNS (灰色)
A@185.199.110.153仅 DNS (灰色)
A@185.199.111.153仅 DNS (灰色)
CNAMEwww你的用户名.github.io仅 DNS (灰色)
关于 Cloudflare 代理 (橙色云朵)：

如果开启 Cloudflare 代理 (橙色云朵)，SSL 模式必须设为 Full 或 Full (Strict)，否则会出现重定向循环。

如果你不确定，先使用 仅 DNS (灰色云朵)，网站正常后再开启代理。

6Cloudflare SSL 配置

  1. Cloudflare 面板 → SSL/TLS → Overview
  2. 加密模式选择 Full（如果开启代理）或 Flexible（如果仅 DNS）
  3. 进入 SSL/TLS → Edge Certificates
  4. 开启 Always Use HTTPS
  5. 开启 Automatic HTTPS Rewrites
  6. 开启 HSTS（可选，增强安全性）
GitHub Pages 自动签发 SSL：GitHub Pages 会自动为绑定的域名签发 Let's Encrypt 证书。首次绑定时可能需要等待几分钟到几小时。

cd blog

# 2. 编辑文章内容 (使用任何编辑器)
#    修改 front matter 中的 draft: false 表示正式发布

8常见问题

Q: 推送后 GitHub Actions 报错？

  • 检查 .github/workflows/hugo.yml 中 HUGO_VERSION 是否与本地一致
  • 确保仓库 Settings → Pages → Source 选的是 GitHub Actions
  • 检查 Actions 日志中的具体报错信息

Q: 域名访问显示 404？

  • 检查 static/CNAME 文件中的域名是否与 GitHub Pages 设置一致
  • GitHub Settings → Pages 中确认 Custom domain 已正确填写
  • 等待 DNS 生效 (可能需要几分钟)

Q: HTTPS 访问出现重定向循环？

  • Cloudflare SSL/TLS 模式改为 Full
  • 或暂时关闭 Cloudflare 代理 (灰色云朵)

Q: 文章没有出现在首页？

  • 检查文章 front matter 中 draft: false
  • 检查文章的 date 是否是未来时间 (未来时间的文章默认不显示)
  • 本地预览用 hugo server -D 可以看到草稿

Q: 如何更换主题？

# 删除旧主题
git rm themes/PaperMod.git
# 添加新主题
git submodule add https://github.com/作者/主题名 themes/新主题名
# 修改 hugo.yaml 中的 theme 字段
